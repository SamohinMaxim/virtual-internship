# API для управления данными о перевалах

## Описание проекта

Это REST API предназначено для приёма и хранения данных о горных перевалах, включая информацию о координатах, уровне сложности, фотографиях и контактных данных автора заявки. Проект может быть полезен для туристических сервисов, сообществ альпинистов и любителей активного отдыха.

## Реализованные возможности

- **Добавление заявки на перевал** с полной информацией (координаты, уровень сложности, фотографии и данные пользователя).
- **Получение данных о перевале по ID** — полная информация о перевале, включая связанные данные (пользователь, координаты, фотографии).
- **Редактирование заявки**, если её статус — `new` (новый).
- **Получение списка перевалов по email пользователя** — все заявки, отправленные конкретным пользователем.

## Технологии

- **Flask** — фреймворк для создания API.
- **PostgreSQL** — база данных для хранения информации.
- **psycopg2** — драйвер для взаимодействия с PostgreSQL.
- **Python 3.x** — язык программирования.
