# Pereval API

REST API для приёма и хранения данных о горных перевалах: координатах, уровне сложности, фотографиях, контактных данных автора заявки.

## Технологии

- **Flask** — веб‑фреймворк.
- **flask-restx** — для генерации Swagger UI и OpenAPI-спецификации.
- **PostgreSQL** — база данных.
- **Python 3.x** — язык реализации.
